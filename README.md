# 📸 InstaGrow AI
Selenium/Playwright-based automation bot to interact with target Instagram accounts, hashtags, and locations.

Status: 80% complete — PACKAGE

## 🚀 Features
*   **Niche Targeting Outreach**: Automatically search and filter posts by specified hashtags and locations.
*   **AI Comment Generator**: Generates human-like, context-aware comments using OpenAI APIs.
*   **Anti-Spam Delay Systems**: Implements randomized sleep delays to avoid account flag limits.

## 🛠️ Tech Stack
*   **Language**: Python 3.10+
*   **Automation**: Selenium, Playwright
*   **AI Engine**: OpenAI API

## 🔮 What's Left to Ship
We need to design a clean graphical user interface or terminal control panel and package the system configuration files. This will allow users to easily run the bot persistently in the background on virtual servers.

## 📦 How to Run Locally
1.  Install requirements:
    ```bash
    pip install -r requirements.txt
    ```
2.  Install Playwright browser binaries:
    ```bash
    playwright install chromium
    ```
3.  Execute setup diagnostics:
    ```bash
    python check_setup.py
    ```
